## 功能介绍

### 🌍 额外地区价格

在 Steam 原价旁追加指定地区的实际商店价格，无需切换当前商店地区，即可查看其他地区的售价。

- 支持商店中的游戏、套餐与捆绑包价格。
- 支持愿望单，包括未打折商品。
- 支持原价与折后价分别显示。
- 提供中国、美国、日本、乌克兰、南亚美元等多个地区选项。
- 可选择是否显示 `CN`、`US` 等地区代码。
- 可指定额外地区价格的显示货币。币种不同时，原价、折后价和购物车地区合计使用自动汇率换算，并以 `≈` 标记。汇率不可用时显示地区原币。

### 🛒 购物车地区合计

在购物车中显示「目标地区预计付款」，便于查看所选地区的商品总价。未能获取目标地区价格的商品会从合计中剔除，并显示数量提示。

登录后，支持补齐的捆绑包在需要扣除已拥有项目时显示「预计补齐」价格：按目标地区的套餐价格及捆绑折扣，剔除当前账号已拥有的套餐或其中游戏已全部拥有的项目，并计入购物车地区合计。没有可扣除的已拥有项目时，直接显示接口整包价格，不计算补齐价，也不添加「预计补齐」标注。套餐中仅部分游戏已拥有时仍按整个套餐计价，订阅提供的游戏不作为永久拥有内容扣除。仅支持整套购买的捆绑包保留整包价格；礼物捆绑包标注整包价，不使用购买者的游戏库计算收礼人的补齐价。数据不足时不计入小计，估算结果以 Steam 结算为准。

> 合计仅供参考。价格获取失败可能与地区限制、网络或接口状态有关，实际可购买情况和付款金额以 Steam 结算页面为准。

### 💱 价格汇率转换

在原始价格旁追加换算结果，支持 Steam 商店、社区市场和结算页面中的价格元素。

- 购物车价格采用独立扫描，即使账号地区货币与目标货币一致，也会识别购物车中以其他币种标价的商品；若无法读取账号地区，则按价格中的币种符号识别来源货币。
- 购物车会在预计总额旁显示所选地区可购买商品的小计，并统计无法取得该地区价格的锁区游戏；额外地区价格扫描无法取得价格时会显示红色“锁区”提示。

- 自动获取汇率，并按设置的有效期缓存。
- 支持手动指定汇率。
- 支持选择目标地区货币、自定义货币符号及其显示位置。
- 支持在社区市场首页禁用转换。
- 保留原始价格，便于对照查看。

### ⚡ 快速加购与购物车管理

在搜索结果、首页列表、推荐列表、愿望单及商店购买区域追加「加入购物车」按钮，在当前页面完成加购。存在多个可购买版本时，可先选择版本。

- **批量导入**：识别商店链接、SteamDB 链接、AppID、SubID 和 BundleID，自动去重并逐项读取购买信息。
- **批量导出**：将当前账号购物车导出为可再次导入的文本，支持覆盖或追加。
- **折扣筛选**：导入和导出可分别启用「仅打折商品」。
- **列表提取**：将当前页面已加载、可识别的商品保存为列表，再前往购物车导入。
- **批量转送礼／自用**：可输入礼物接收人的 SteamID 或好友代码，也可暂不指定接收人。
- **列表管理**：输入自动保存，支持复制、清除文本和重新读取。
- **购物车管理**：提供购物车历史入口、刷新和清空购物车操作；清空前需确认。
- **显示选项**：支持中文／英文工具文案，以及在页头显示账号地区。

### ⏳ 折扣倒计时

在愿望单及商店首页、搜索、推荐等列表中，为当前可见且正在打折的游戏显示折扣结束时间和剩余时间；通过游戏详情信息读取结束时间，不会为未打折商品或不在列表中的游戏添加倒计时。可在设置中关闭。

### 游戏悬停详情

在商店首页、搜索结果、推荐列表和愿望单中，鼠标停在游戏条目上时，详情卡从条目左侧弹出。左侧空间不足时，卡片会移到视窗内的上方或下方。卡片显示发行商、开发者、系列、好评率和评测总数、抢先体验状态、界面／完整音频／字幕支持、前五个用户标签及简要介绍。可将鼠标移到卡片上滚动查看，也可在设置中关闭此功能。

### 💬 好友批量留言

在 Steam 好友列表中选择好友后，可向所选好友的个人主页逐个发送相同评论。发送前会确认目标人数，发送过程中每位好友之间间隔 4 秒，并显示成功或失败结果。

工具区位于好友页原生管理区域下方，使用「留言／留言设置／数据分析」标签页布局。复选框直接显示在 Steam 好友卡片上，留言和分组共用勾选结果；发送进度显示在「留言」标签页中。

### 👥 好友分组

在好友页创建本地自定义分组，将已加载好友加入或移出分组，并查看每组成员数量。分组数据按当前 Steam 账号分别保存在本地，不会修改 Steam 好友备注或好友关系。

好友页会统计当前已加载好友数、可识别的在线好友数和本地自定义分组数。统计随 Steam 好友列表动态更新；数据仅基于当前页面已加载的好友，不代表账号的完整好友总数。

### 👨‍👩‍👧‍👦 家庭库游戏标记

扫描已加入的 Steam 家庭组，将可共享游戏保存到本地，在浏览商店时识别家庭库中已有的游戏。

- **列表标记**：在首页、搜索、分类及愿望单的可识别商品旁显示「在家庭库中」，支持动态加载和新版愿望单。
- **详情页提示**：显示家庭拥有提示、贡献者人数、贡献者信息和「马上开玩」入口。
- **贡献统计**：查看每位成员拥有的游戏数量，并按共同拥有的成员人数分段显示。
- **导航快捷入口**：商店导航的愿望单按钮左侧显示「我的家庭库」和缓存游戏数量，点击直接打开统计与管理页面。
- **图表悬浮详情**：鼠标移到柱条分段上，显示成员、共同拥有人数、该分段游戏数、成员游戏总数及占比；也支持键盘聚焦查看。
- **最近购入**：按接口记录的最早购入时间排序，支持搜索游戏和贡献者；最近 30 天购入且只有一位成员拥有的游戏以绿色突出显示。
- **其乐支持**：在其乐社区的 Steam 游戏链接旁标记家庭库存，在 `steamdb.keylol.com` 游戏提示页补充贡献者信息。
- **缓存管理**：支持手动扫描、每隔 24 小时自动扫描及确认后清空缓存。切换账号后，Steam 页面不会使用其他账号的家庭缓存。

列表标记主要提示当前账号尚未拥有、家庭成员已拥有的游戏；当前账号也拥有的游戏仍可在详情页查看贡献者信息。

### ⚙️ 统一设置

使用 Steam 风格的深色弹窗，集中管理各项功能。功能可独立开关，地区价格与汇率转换可分别选择目标地区。

### 🚦 游戏受限状态

在可识别的 Steam 游戏标题旁显示小方块标签：绿色「非受限」、黄色「Steam 正在了解」、红色「受限」。这里指个人资料功能限制，与商店地区锁区不同。

优先使用 [F1NN1ER 的受限游戏数据库](https://github.com/F1NN1ER/getSteamRestrictedGameLIst)，缺失或状态无效时自动读取 Steam 商店页面。无效数据经补查仍无法确认时显示灰色「无效」；网络失败、年龄验证或页面不完整不会被判为非受限。

数据库保留 GitHub Raw、jsDelivr 和 jsDelivr Fastly 来源。每次需要刷新时先并行小范围测速，按速度下载，失败自动切换；可取得最新提交号时按同一提交读取，减少 CDN 分支缓存延迟。数据库成功更新后整份覆盖本地缓存，自动移除旧快照中的记录，不累积历史版本。缓存有效期为 24 小时，长时间打开的页面也会自动检查；过期时先用已有缓存显示，再后台更新标签。更新失败保留有效旧缓存并在 15 分钟后重试。

查询顺序为数据库、独立的 Steam 补查缓存、Steam 请求。Steam 已确认状态长期保存，不按时间或条数自动清除，数据库更新也不清除这份缓存。Steam 补查串行执行，请求开始至少间隔 4 秒；遇到 HTTP 403/429 或连续三次无法确认时进入 15–60 分钟冷却，冷却状态跨刷新保留。支持 Web Locks 的同源标签页会协调请求；不同域名之间不保证严格互斥。限速可以减少请求压力，但不能保证 Steam 不会限制访问。

油猴弹出菜单的「设置」下方提供「清除缓存」：清除受限数据库、Steam 补查及限速记录、家庭库和汇率缓存，并刷新当前页以释放内存缓存。设置、好友分组和购物车清单保留。其他已打开的页面需刷新后释放各自的内存缓存。

支持详情页及可识别的搜索、首页列表、社区推荐、无限滚动推荐、愿望单和社区游戏标题，并监听动态加载。没有可见标题的纯图片卡片暂不追加标签。Steam 补查无法确认状态时，页面保持打开也会在 15 分钟后重试。设置中的「显示游戏受限状态」可关闭此功能。

## 显示示例

假设当前商品售价为 **$10.00**，设置人民币换算后为 **￥80**，而中国区实际售价为 **¥32.00**，页面会显示类似：

```text
$10.00(￥80) (CN ¥32.00)
       ↑          ↑
    汇率换算    中国区实际售价
```

**地区售价**来自目标地区的 Steam 定价；**汇率换算**根据当前显示的价格计算。两者用途不同，结果也可能不同。

## 安装使用

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 前往 [Greasy Fork 的 Steam Store Enhancer 页面](https://greasyfork.org/zh-CN/scripts/605911-steam-store-enhancer)，点击安装并在 Tampermonkey 中确认。
3. 打开或刷新 Steam 页面。
4. 点击 Tampermonkey 图标，选择 **「设置」**。
5. 根据需要调整选项，点击 **「保存并刷新」**。

也可以从本项目下载 [Steam Store Enhancer.user.js](./Steam%20Store%20Enhancer.user.js)，再通过 Tampermonkey「实用工具 → 从文件导入」手动安装。

如果已安装功能相同的地区价格、汇率转换、快速加购或家庭库标记脚本，请先停用，以免重复显示。

## 开发

需要安装 [Node.js](https://nodejs.org/) 20 或更高版本。功能源码按模块保存在 `src/` 目录中，修改源码后在项目根目录运行：

```sh
npm run build
```

构建会将 `src/` 中的模块合并，生成可直接安装的 `Steam Store Enhancer.user.js`。请修改 `src/` 中的源码，不要直接编辑生成文件。

模块职责和日志接口见 [维护说明](docs/architecture.md)。日志核心位于 `src/logging/`，转换设置、汇率服务、价格文本处理分别位于 `src/conversion/`；公共请求队列位于 `src/network.js`。模块的构建顺序由 `scripts/build.mjs` 定义。

页面功能由 `src/main.js` 按页面与单项设置协调，GM 设置变更时只重启受影响的功能。价格转换使用有并发上限的异步工作池处理动态 DOM，避免大型页面同时创建过多任务；网络请求仍遵守各自队列与 Steam 限速策略。

运行以下命令检查生成文件是否与源码一致、逐个验证仓库内 JavaScript（源码、构建脚本、测试和生成文件）的语法，并执行测试：

```sh
npm run check
npm test
```

### 自定义汇率示例

将美元价格换算成人民币，假设 **1 美元 = 8 人民币**：

- 价格转换目标地区选择「中国」。
- 开启「使用自定义汇率」。
- 自定义汇率填写 **`0.125`**，即 1 人民币可兑换 0.125 美元。

计算方式为 `原金额 ÷ 自定义汇率`，因此 `$10 ÷ 0.125 = ￥80`。自定义汇率会应用于所有命中的原币种，查看多种货币时建议使用自动汇率。

切换目标地区货币后，可同时调整货币符号，使显示与所选货币一致。

## 批量导入购物车

打开 Steam **购物车页面**，在「购物车工具」文本框内填写商品，每行一条，例如：

```text
730                             # 纯数字按 AppID 识别
app/570                         # 游戏
sub/123                         # 套餐，示例 ID 请替换
bundle/456                      # 捆绑包，示例 ID 请替换
https://store.steampowered.com/app/730/
https://steamdb.info/app/570/
```

也支持 `a/`、`s/`、`b/` 简写；`#` 后面的内容作为备注忽略。点击「导入」后，工具会读取购买信息，将符合条件的商品提交到账号购物车，并在文本框中记录处理结果。

批量导入 AppID 时默认采用接口返回的第一个可购买版本。需要指定版本时，请使用对应的 `sub/` 或 `bundle/`，或通过页面快速加购按钮选择版本。完成加购或批量修改后，点击「刷新购物车」查看 Steam 的最新结果。

快速加购和购物车管理需要登录 Steam 商店，始终使用**当前账号地区**；设置中的额外显示地区及换算目标地区不会改变实际加购地区。免费游戏、未发行游戏或受地区限制的商品可能没有可用购买项。

「转送礼」时，输入框留空可暂不指定接收人，点击取消则停止操作；送礼和自用转换都会将所处理商品的私密购买标记关闭。

## 使用家庭库标记

在已登录且已加入家庭组的 Steam 商店页面，打开脚本设置，点击 **「管理家庭库：扫描、贡献统计与最近购入」**，再点击 **「现在扫描家庭库」**。扫描成功后即可查看成员贡献和游戏列表，页面上的家庭库标记也会同步更新。

自动扫描开启时，脚本会在打开 Steam 商店页面且缓存缺失或超过 24 小时时尝试后台扫描。未登录、未加入家庭组或接口暂时不可用时，会在家庭库管理页面显示原因，不覆盖原有缓存。其乐页面只读取本脚本保存的缓存，需要先到 Steam 商店完成扫描。

家庭库数据由 Steam 家庭接口提供，实际共享资格和同时游玩的可用份数以 Steam 客户端为准。接口提供的是游戏记录的最早购入时间，无法据此准确判断每位成员各自的购买时间。

旧家庭库脚本与本脚本的油猴存储相互独立，首次使用请重新扫描；家庭缓存不保存访问令牌。

## 支持页面

| 页面 | 额外地区价格 | 汇率转换 | 购物车工具 |
| :--- | :---: | :---: | :--- |
| Steam 商店 | ✓ | ✓ | 适配列表及购买区快速加购、列表提取 |
| 愿望单 | ✓ | ✓ | 快速加购、列表提取 |
| 购物车 | ✓，含地区合计 | ✓ | 导入导出、送礼／自用及列表管理 |
| Steam 社区及市场 | — | ✓ | 存在可识别商品列表时提供加购入口 |
| Steam 结算页面 | — | ✓ | — |

脚本通过 Steam 接口获取地区价格，通过 Augmented Steam 汇率服务获取自动汇率。页面显示范围取决于 Steam 的页面结构与价格元素，Steam 更新页面后可能需要相应适配。

家庭库标记覆盖 Steam 商店中的适配商品列表、游戏详情及愿望单，以及 `keylol.com` 和 `steamdb.keylol.com/tooltip` 页面。
